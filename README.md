# Wordle Ariketa

Proiektu hau Wordle jokoaren inplementazio txiki bat da, HTML, CSS eta JavaScript erabiliz garatua. Interfazea HTML egiturekin eraiki da, CSS bidez estiloztatu da eta jokoaren logika JavaScript-en ezarri da.

Gainera, LocalStorage erabiltzen da jokalariaren aurrerapenaren informazioa gordetzeko, hala nola saiakerak eta partidaren egoera, beraz, geroago jarraitu edo informazioa ikusi ahal izateko datuak galdu gabe.

## Erabilitako teknologiak

- HTML
- CSS
- JavaScript
- LocalStorage
